# GrowCode

## A Scalable and Resource-Aware Platform for Multi-User Code Execution and Management

GrowCode is a locally hosted, multi-user coding practice platform with an
integrated online judge.

The project demonstrates concepts from:

- Operating Systems
- Database Management Systems
- Process Management
- Process Scheduling
- Multithreading
- Synchronization
- Inter-Process Communication
- Resource Management
- Relational Database Design

## Technology Stack

- HTML
- CSS
- JavaScript
- C++
- MySQL

## Project Architecture

GrowCode follows a client-server architecture where multiple users connect
to a central server through web browsers.
